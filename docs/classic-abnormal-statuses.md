## 已落实的行为

下表概述官方说明及对应实现。

| 异常 | 官方描述的基本行为 | 本项目 Buff ID |
| --- | --- | --- |
| 中毒 | 弱化类；在对手开始行动时失去最大体力的八分之一 | 10021 |
| 烧伤 | 同样失去体力，且攻击技能威力减半 | 10023 |
| 冻伤 | 弱化类；扣体力方式与中毒一致 | 10024 |
| 疲惫 | 控制类，阻止精灵行动 | 10025 |
| 麻痹、害怕 | 控制类，阻止精灵行动 | 10061、10062 |
| 睡眠 | 控制类；敌方未 miss 的攻击技能可解除 | 10063 |

中毒、烧伤、冻伤共用 `poison_tick.lua`，监听 `BeforeTurnStart`，只在对方行动时触发；经 LoseHp 处理，不当作攻击伤害，不经过暴击、克制或护盾减伤。每个实例每轮最多触发一次，重入不能重复扣血。现有 HP 变更/失去体力时机仍可拦截。

烧伤在 `BeforeSkillDamageCalculation` 修改本次 `SkillUseData.power`，同时覆盖物理/特殊技能；不会改 Skill 配置或在通用 Damage 事件里减半。计算器仍独立可调用，`calculation.power` 保存实际代入威力。被动定值元素伤害不经过技能修正。

疲惫在 `BeforeSkillUse` 阻止攻击技能与属性技能，不消费 PP。本项目保留道具、换宠通道；这与基础行动分离的现有架构一致，但官方配置中“无法行动”的一句话不足以独立证明所有特殊道具/换宠限制。

## 持续时间和兼容边界

- 继续由统一 `ResolveRoundEnd` 扣轮、同步和到期移除，具体效果不自行减轮。
- 持续轮数可由施加来源传入。`10019 / apply_abnormal.lua` 复用 `ctx:inflictAbnormal`：默认随机 2～3 轮，支持概率、固定轮数或随机轮数范围。此默认值按用户指示设置，不据此宣称所有官方异常均有相同轮数。新增技能 10035～10040 是施加三轮异常的演示配置，不声称对应官方同名技能；原中毒示例也迁至此骨架，旧 10014 保留兼容。
- 本轮中途新增的经典异常先保留后续完整轮数；若本轮已实际扣血或阻止技能，则本轮开始计时。共享 `abnormal_duration.lua` 只设置首次计时轮次，最终扣轮仍由引擎执行。这是为避免“刚施加就到期、一次也未生效”的项目计时约定；官方说明没有明确给出完整持续时间算法。
- 扣血延续已有整数规则：向下取整、至少 1 点。官方描述只给出比例，没有公开取整方式，因此此边界尚不能称为官方验证通过。
- 同编号有效 Buff 或同 abnormalKind 的有效异常仍拒绝重复，不自动刷新或叠层；不同编号仍允许并存。官方包中的基础描述未充分说明续时、叠加、互斥及异常抗性，尚未把这些现有默认行为认定为官方规则。
- 沿用用户指定的下场默认清除；`keepOnSwitch`、玩家方印记沿用已有通用机制。
